# Armor correction proof 05

Fresh native six-part proof after the interrupted proof-04 build. Proof-04 is
preserved unchanged; its empty build log does not establish a completed asset.

This revision terminates the navy upper/lower rail geometry before pale connector
shoe intervals. The cap front, horizontal return and depth faces now have one
visible owner. The bow and shoulder frame ends follow the same repair. Sparse
construction courses remain mapped relief. The cassette plane remains X=0.28125 m,
the frame remains inside X=0.5 m, and the 2 m side interfaces are unchanged.

`source.blend`, `recipe.py`, the frozen interface JSON, packed map files and six
GLBs are retained with exact hashes in `models.json`. Both `validation.json` and
`validation-strengthened.json` pass. The latter adds checks for socket normals,
1/32 m socket coordinates, UV range, opaque material mode and byte-identical
embedded base-color/normal PNGs. Combined output: 3436 triangles.

All seven `renders/` images are fresh exact-GLB imports, captured serially with
Cycles CPU at four threads. `renders/captures.json` records hashes, transforms,
camera and lighting context. Unused imported datablocks are purged between views.

The independent reviewer inspected all seven native views and confirmed the
prototype direction and cap repair. The initial full-family propagation gate
also requires the coordinator's matching actual game-loader view and the
reviewer's saved decision. Native technical checks do not grant owner artistic
sign-off, publication permission, or pressure/damage qualification.
