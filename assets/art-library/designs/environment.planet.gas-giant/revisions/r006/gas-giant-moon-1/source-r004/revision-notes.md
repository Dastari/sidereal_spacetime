# r004 material metadata correction

r003 exported native polished mineral coats correctly but used JSON property names that the isolated adapter does not consume. This successor corrects only those two property names. All native Blender/GLB bytes, geometry and texture maps remain byte-identical to r003. The preserved generator.py is the r003 native-source generator; metadata-correction.json records this subsequent adapter correction. Actual optical reference review remains pending.
