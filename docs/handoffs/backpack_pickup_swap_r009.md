Ground item holograms display ALL CAPITALS. Picking up a ground backpack with an empty back slot equips it directly, without requiring inventory room. With an occupied slot, primary pickup retains normal storage behavior; right-click the ground nameplate and choose Swap backpack to replace it. The server transfers the old pack's direct contents into the new pack, retaining every nested UUID and liquid row. It preserves the new pack's existing layout, validates contiguous Tetris rectangles and mass, then returns the empty old pack to the incoming source where valid. If the source cannot hold it, the normal standing-character drop validator creates a ground wrapper at the server-derived actor position. Everything is planned before item writes. Rejected fit/payload/carry/reach/ownership/drop requests preserve items, containers, bindings and revision. Historical successful requests cannot replay an old swap after later equipment changes.
