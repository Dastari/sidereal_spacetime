## Hot-reload lifecycle limitation

The combined development browser recorded182 WebGL invalid-operation warnings during a session containing repeated source hot reloads (`.playwright-cli/console-2026-09-10T05-30-16-901Z.log`, first deleted-program warning at521027ms). A subsequent fresh full reload followed by Objects-ready → Systems-ready → Rooms → Systems, with no source edits, passed with0invalid operations and GL error0. Thus the noisy hot-reload session is not evidence of an error-free session, while the isolated normal mode-transition check passed.

Read-only inspection identifies a plausible specific overlap, not yet an instrumented causal proof: `createHullViewport.dispose` stops rendering immediately but defers scene/engine disposal until pending GLB imports and scene readiness settle. Fast Refresh can rerun the effect on the same mounted canvas in that interval. Repeated getContext calls on that canvas return the same WebGL context. Babylon9.25 GPU pipelines are cached per context (`thinEngine.functions.js` WeakMap), and engine disposal deletes its programs and that context's cache; an old engine can therefore invalidate a replacement using the same canvas/context. Distinct normal unmounted canvases do not share this cache. No blanket shader-cache reset, material mutation or renderer rewrite was added. A future bounded fix should serialize ownership of a reused canvas through completion of asynchronous disposal, with a repeated hot-reload/recreate GPU regression. Parent retains the stable-source normal mode-transition evidence for this release.

## Drawn-floorplan 3D structural guides

The fresh editable ship path now has an optional `HullViewState.structuralGuide: LayoutStructuralGuide` with `{walls, deckId, elevationUnits, heightUnits}`. Values use the compiler's1/32m units. `createAssemblyLayoutPreview` supplies active-deck values directly; HullWorkspace consumes the same API through parent wiring. `layoutStructuralLines` traces only `CompiledLayout.walls` (already split around valid openings), never imported/retained wall parts. One non-pickable line mesh shows each span's floor/top/jamb outline at its deck height. These are explicit technical authoring guides, not Blender art, placed fittings, pressure seals or collision authority.

The guide obeys active deck and Walls/category visibility, shares no geometry with retained native assets, and coexists with matched native floors. Unmatched floor guides use the same deck elevation. Unchanged or same-sized edited line geometry is reused; count changes reallocate one mesh, an empty wall set removes it, and viewport disposal releases it. Fit includes visible guide bounds, enabling a blank assembly with drawn floors/walls to frame its3D extent.
