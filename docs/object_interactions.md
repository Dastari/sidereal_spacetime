# Proximity object interactions

Status: Authoritative fixture published additively; client/render integration and live browser acceptance passed.
Date: 2026-09-08

The first slice uses approved placed IDs from `assets/art-library/shipyard-equipment/publication.json`: `room-lounge` and the three `room-hydroponics-tray-*` placements. Content interaction definitions are separate from external equipment model assets. Private object rows receive stable server UUIDs through idempotent lab entry; no model file is modified. Existing labs seed the rows by re-entering through the authorized idempotent path.

`ownInteractions` projects object UUID, placement ID, asset ID, display name, kind, local XY, revision, enabled, occupied, seatedByYou and reachable. It exposes only the authenticated connected character's private lab, without owner, ship or occupant identifiers. Reach is 1.8 metres from the authoritative placed-object position with a partition visibility check through the authored approach point. Showing a selected distant object does not authorize its action.

`interactObject({objectId, action, expectedRevision, operationId})` supports `sit`, `stand`, `set-light-on` and `set-light-off`. Consumption rechecks connected character, lab membership, proximity, partition visibility, action kind, occupancy and expected revision. Exact request retries do not apply twice; changed requests with a reused operation ID reject. Receipts retain at most 128 operations per character; revision checks protect replay after pruning. Mutations are atomic.

The sofa uses a separate private couch occupancy row. Sitting clears movement/flight intent and any helm occupancy, freezes walking, and grants no piloting permission. Standing restores a clear authored adjacent location and clears intent. Disconnect also releases the sofa. Using the helm while on the sofa requires standing first. Couch presentation should use `seatedByYou`; neither it nor helm occupancy implies changing camera mode.

Each hydroponics tray has an independent persistent light flag. The renderer maps its placed ID to actual native fixture lights and placement-local cloned emissive materials, preserving approved source materials and the other trays. Missing/disconnected projections switch controlled lamps off. This is authoritative light state, but it does not implement fuel/electrical networks, crop progression or production power simulation. Doors are not authored in this slice and no fictional door action is exposed; another kind/action can be added through the same validator structure later.

Pure tests cover reach, occupied seats, valid action kinds and partition visibility. Isolated smoke covers absent/foreign actors, private table rejection and redacted views, stable fixture IDs, range loss, sofa movement inhibition without helm control, CAS/retry/conflicting operations, grow-light persistence and disconnect release. Normal additive publication subsequently passed without resetting the development database.

Clicking visible installed equipment now selects its placed object, outlines its model, and opens an independent movable details window with its approved PNG, readable name, dimensions and available live status. The ray tests the first visible surface so walls block hidden targets. UI-consumed clicks do not select the world. Unsupported equipment such as the medical bed remains inspectable without invented health/healing actions or statistics. Existing pilot-seat and console actions delegate to the validated control-station reducer.

Live browser review at the required preview origin passed sofa, medical-bed and hydroponics ray selection, distant disabled actions, window dragging, seated movement inhibition, and independent grow-light off/on via both E and the detail action. All other trays retained their original light/material values. Entering the helm preserved Deck view; W/S changed authoritative flight velocity in that view, and Tab switched to Flight while retaining the station. Couch occupancy has its own Seated HUD state and grants no flight controls. See [object UI evidence](object_details_ui_iteration.md).
