## Whole-object silhouette correction

The owner rejected the thin per-primitive outlines around individual sofa cushions. Selection now uses one depth-tested binary mask for all primitives of the placed object and a three-render-pixel circular dilation minus the original mask. This leaves a thicker cyan exterior boundary with no interior material seams. The mask uses temporary render-pass materials; authored model materials remain untouched. Visible ship geometry occludes it, including still-visible cutaway transitions; disabled roofs and retained invisible shadow proxies do not participate. The render target, postprocess, temporary materials and resize observer are disposed when selection clears, so unselected gameplay has no additional selection pass.

A first Babylon HighlightLayer attempt produced the desired open-view union but failed the roof-transition test: transparent blockers erased main stencil while leaving cyan in the highlight texture, filling occluded parts cyan. That attempt was rejected. The binary-mask implementation removes the main-stencil dependency. Actual binary-mask browser comparisons passed: `object-silhouette-deck-final.png`, `object-silhouette-occlusion.png`, `object-silhouette-distance.png` and `object-silhouette-resized.png`. The old cyan fill disappeared; retained/transitioning roofs occlude selection. Resize matched the 900×620 framebuffer exactly, and clearing selection removed both mask target and edge postprocess. A subsequent owner-reported selection initialization flash is being corrected separately.
