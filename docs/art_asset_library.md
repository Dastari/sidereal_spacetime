# Living art asset library

The owner-requested reference inventory and iterative review system starts at [assets/art-library/INDEX.md](../assets/art-library/INDEX.md). Use its [agent workflow](../assets/art-library/WORKFLOW.md) for all reference-led art work and progress reports.

Replacement models follow the owner's [Blender migration direction](blender_asset_migration.md): TypeScript voxel-solid art is being phased out in favor of authored Blender meshes and materials. The [equipment redesign prompt](../assets/art-library/prompts/REDESIGN_CURRENT_EQUIPMENT.md) and [equipment queue](../assets/art-library/CURRENT_EQUIPMENT.md) make that explicit for the ten current Shipyard designs and seventeen placements.

The initial inventory visually inspects all 33 source files, preserves exact crops and per-item briefs, identifies the duplicate/mislabeled sheet, groups repeated appearances into proposed shared design queues, and tracks immutable revisions, feedback, evidence and explicit owner final sign-off. The [source audit](../assets/art-library/SOURCE_AUDIT.md) and [style/pipeline mapping](../assets/art-library/STYLE_AND_PIPELINE.md) document coverage, scale conflicts and implemented versus proposed capabilities. The [local visual browser](../assets/art-library/index.html) provides search and filters without writing approvals or publishing assets.

An extracted reference is not a reconstructed cutout, a Blender asset, a runtime capture or a final design. The ledger records only artifacts that actually exist. The owner chose source crops plus reconstructed cutouts, sharing canonical designs across repeated appearances while preserving every crop. Future agents must retain revision history and real Blender/in-game evidence, record owner feedback verbatim, and never infer final approval.

The initial checkpoint contains 2,369 source appearances, 224 preserved crop-framing corrections and six explicit construction targets among 340 design queues. Those six have initial transparent Blender/voxel reconstructions and actual dashboard Shipyard captures. The remaining families still need their reconstructed cutouts and production work. The Shipyard captures use isolated browser draft assets; the overhead camera is a documented review override. They are not published assets or a live-game acceptance test. See the current JSON status rather than treating these checkpoint counts as permanent.

Open `assets/art-library/index.html` or run `npm run art:library:serve` for the local browser. Per-design visual histories show source crops, successive renders, feedback and evidence downloads together. `npm run art:library:check` verifies saved hashes, revision invariants, the mesher's types and isolated workflow tests. Source-pixel verification is `.tools/art/bin/python scripts/art_catalog.py check --deep`.
